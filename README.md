# Laputian — Support

**Laputian** is a quiet daily companion for people living with ADHD.

## 주요 기능 / Features

| 기능 | 설명 |
|------|------|
| **앵커 이벤트** | 오늘 가장 중요한 일정 하나를 선택하고 카운트다운 |
| **스마트 루틴** | 습관 시간을 학습해 적절한 타이밍에 넛지 |
| **투약 관리** | 한 탭 복용 기록 + 약효 카운트다운 + 의사 공유용 보고서 |
| **장소 학습** | 방문 장소를 온디바이스로 학습, 외부 서버 전송 없음 |
| **위젯** | 홈화면·잠금화면에서 앵커·투약 상태 한눈에 확인 |
| **AI 지원** (프리미엄) | 앵커 제안, 스마트 체크리스트, 맞춤 넛지, 하루 마무리 격려 |
